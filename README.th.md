DeepSeek Harness คือเอเจนต์เขียนโค้ดด้วย AI ที่รันอยู่บนคอมพิวเตอร์ของคุณและมีหน้าเว็บไว้ใช้งาน
DSH Mobile เชื่อมต่อกับ harness ตัวนั้น แล้วให้คุณสั่งงานได้แบบเดียวกันผ่านแอป Android แบบเนทีฟ
คุณเริ่มงานไว้ที่โต๊ะทำงานได้ จากนั้นก็ตามดูงาน ตอบคำถาม และอนุมัติคำสั่งของมันจากมือถือ

แอปนี้ไม่ใช่แอปทางการ แต่เป็นแอปที่ชุมชนสร้างขึ้น และต้องมี harness รันอยู่ในที่ที่แอปเข้าถึงได้
จะเป็นบนคอมพิวเตอร์ของคุณ หรือบนตัวมือถือเองผ่าน Termux ก็ได้

[เว็บไซต์ของโปรเจกต์](https://dshm.zyphite.com) สรุปภาพรวมไว้ในหน้าเดียว ส่วน
[wiki](https://github.com/sorsama/deepseek-harness-mobile/wiki) มีคู่มือผู้ใช้ฉบับเต็ม

## ทำอะไรได้บ้าง

- แชทกับเอเจนต์ คำตอบจะสตรีมเข้ามาพร้อมการให้เหตุผล บล็อกโค้ด และการเรียกเครื่องมือ
  คุณแนบรูปภาพและไฟล์ได้ อ้างถึงไฟล์ด้วย `@` และเรียกใช้คำสั่งกับสกิลด้วย `/`
- กดค้างที่ข้อความ การเรียกเครื่องมือ หรือไฟล์ เพื่อดูว่าทำอะไรได้อีก เช่น คัดลอก
  แก้ข้อความที่ส่งไปแล้วส่งใหม่ หรืออ้างถึงไฟล์ในข้อความถัดไป
- ตอบสิ่งที่เอเจนต์ต้องการจากคุณ ทั้งอนุมัติหรือปฏิเสธคำสั่ง ตอบคำถามของมัน
  และตรวจแผนก่อนที่มันจะเริ่มทำงาน
- ติดตามงานที่ใช้เวลานาน เป้าหมาย รายการสิ่งที่ต้องทำ ข้อความที่รอคิว งานเบื้องหลัง และซับเอเจนต์
  ต่างก็มีหน้าแสดงของตัวเอง และคุณสั่งหยุดชั่วคราว ชี้นำ หรือหยุดได้
- จัดเรียงเซสชันตามที่คุณชอบ ลากไปวางตามลำดับที่ต้องการ หรือจัดกลุ่มตามโปรเจกต์
  แล้วพับกลุ่มที่ไม่ได้ใช้เก็บไว้
- ค้นหาด้วยช่องค้นหาแบบเดียวกันทุกที่ ทั้งเซสชัน โมเดล คำสั่ง ปลั๊กอิน งานที่ตั้งเวลาไว้
  และไฟล์ในพื้นที่ทำงาน
- รับการแจ้งเตือนเมื่อเทิร์นจบ เมื่อเป้าหมายสำเร็จหรือติดขัด หรือเมื่อเอเจนต์รอคำตอบจากคุณ
  แอปจะคงการเชื่อมต่อไว้ในเบื้องหลัง
- เรียกดูและดูตัวอย่างไฟล์ในพื้นที่ทำงาน และเปิดเทอร์มินัลบนคอมพิวเตอร์ที่รัน harness
- เปิดไฟล์เต็มหน้าจอในตัวอย่าง ทั้งตาราง CSV แผนผัง JSON โน้ตบุ๊ก PDF รูปภาพ วิดีโอ เสียง
  และไฟล์บีบอัด พร้อมค้นหาในไฟล์ และ “บันทึกสำเนา” จะเก็บไฟล์ใดก็ได้ไว้ในโทรศัพท์ของคุณ
- จัดการตัว harness เอง ได้แก่ โมเดล พรีเซ็ตเอเจนต์ ปลั๊กอิน งานที่ตั้งเวลาไว้
  และเซสชันที่เก็บถาวร
- ปรับแอปให้เป็นแบบของคุณ ดีไซน์ Ink มีทั้งโหมดสว่างและมืด สีเน้นที่ตั้งไว้ให้หรือสีที่เลือกเอง
  สีดำสนิทสำหรับจอ OLED และขนาดตัวอักษรที่ปรับได้
- ใช้แอปเป็นภาษาอังกฤษ จีน ฮินดี สเปน ฝรั่งเศส อาหรับ เบงกาลี โปรตุเกส
  รัสเซีย อูรดู หรือไทยก็ได้ และรองรับภาษาที่เขียนจากขวาไปซ้าย

ดูว่าแต่ละรุ่นเปลี่ยนอะไรไปบ้างได้ที่ [บันทึกการเปลี่ยนแปลง](CHANGELOG.md)

## เริ่มต้นใช้งาน

### 1. ติดตั้งแอป

ดาวน์โหลด APK จาก [รุ่นล่าสุด](https://github.com/sorsama/deepseek-harness-mobile/releases/latest)
แล้วติดตั้ง ต้องใช้ Android 8.0 ขึ้นไป

### 2. ทำให้แอปเข้าถึง harness ได้

โดยค่าเริ่มต้น harness จะรับการเชื่อมต่อจากเครื่องของมันเองเท่านั้น
ให้เลือกวิธีตั้งค่าที่ตรงกับว่ามือถือของคุณจะอยู่ที่ไหน

#### ใช้ Wi-Fi วงเดียวกับคอมพิวเตอร์

เริ่ม harness บนที่อยู่ในเครือข่ายภายในของคอมพิวเตอร์ สำหรับ
harness 0.2.1-alpha.2 ขึ้นไป:

```sh
dsh web --host 192.168.1.20
```

ใส่ที่อยู่จริงของคอมพิวเตอร์คุณแทน `192.168.1.20` แล้ว harness จะพิมพ์บรรทัดประมาณนี้ออกมา
`dsh web: http://192.168.1.20:3080/?token=…` ในแอปให้เลือก **เครือข่ายภายใน**
วางลิงก์นั้นทั้งลิงก์ลงในช่องที่อยู่ (หรือแตะปุ่มวาง) แล้วแตะ **เชื่อมต่อ** โทเคนในลิงก์จะลงชื่อเข้าใช้ให้มือถือ
และครั้งต่อไป harness นี้จะอยู่ในรายการ **ล่าสุด** ส่วน harness เวอร์ชันเก่ากว่านี้ต้องใส่แพตช์เล็ก ๆ
แทนการใช้ `--host` ดู [`harness/README.md`](harness/README.md)

#### อยู่นอกบ้าน

ติดตั้ง [dsh-relay](https://github.com/sorsama/deepseek-harness-relay)
ซึ่งเป็นปลั๊กอินของ harness ที่เพิ่มรหัสผ่าน การเข้ารหัส และการจับคู่อุปกรณ์
จากนั้นเลือก **รีเลย์** ในแอปแล้วสแกนคิวอาร์โค้ดสำหรับจับคู่ [หน้า Relay ใน wiki](https://github.com/sorsama/deepseek-harness-mobile/wiki/Relay)
อธิบายขั้นตอนไว้ทีละขั้น

#### สาย USB หรืออีมูเลเตอร์

รัน `dsh web` บนคอมพิวเตอร์ และรัน `adb reverse tcp:3080 tcp:3080`
ในแอปให้เลือก **เครื่องนี้** แล้วลงชื่อเข้าใช้ด้วยลิงก์ที่ `dsh web` พิมพ์ออกมา

#### บนตัวมือถือเอง

harness รันใน [Termux](https://f-droid.org/packages/com.termux/) ได้
เลือก **เครื่องนี้** แล้วแอปจะเริ่มและหยุด harness รวมถึงลงชื่อเข้าใช้ให้คุณได้
การติดตั้ง Node ใน Termux ยังใช้ไม่ได้กับทุกเครื่อง ควรอ่าน [`harness/TERMUX.md`](harness/TERMUX.md)
ก่อน

#### รีเวิร์สพร็อกซี HTTPS ของคุณเอง

วางที่อยู่ `https://` ของพร็อกซีในโหมด **เครือข่ายภายใน**
พร็อกซีจะเข้ารหัสการเชื่อมต่อ แต่ไม่ได้ตรวจว่าใครเป็นคนเชื่อมต่อเข้ามา ดู
[`harness/README.md`](harness/README.md)

### 3. เริ่มทำงาน

เลือกเซสชันจากรายการ (ปัดเข้ามาจากขอบซ้าย) หรือเริ่มเซสชันใหม่
ถ้าเชื่อมต่อไม่สำเร็จ แอปจะบอกสาเหตุ และ
[หน้าการแก้ปัญหา](https://github.com/sorsama/deepseek-harness-mobile/wiki/Troubleshooting) ใน wiki
ก็จัดเรียงตามข้อความเหล่านั้น

## ความปลอดภัย

อ่าน [docs/SECURITY.md](docs/SECURITY.md) ก่อนเชื่อมต่อผ่านเครือข่าย
มือถือที่ลงชื่อเข้าใช้แล้วทำได้ทุกอย่างที่เอเจนต์ทำได้ และเอเจนต์รันคำสั่งบนคอมพิวเตอร์ของคุณ
ให้มองการลงชื่อเข้าใช้ว่าเท่ากับการให้สิทธิ์เข้า shell

- โหมดเครือข่ายภายในตรวจโทเคนลงชื่อเข้าใช้ แต่ไม่ได้เข้ารหัสอะไรเลย
  ใช้เฉพาะบนเครือข่ายที่คุณไว้ใจเท่านั้น
- โหมดรีเลย์เพิ่มการเข้ารหัสและใบรับรองที่ปักหมุดไว้ และใช้งานจากนอกเครือข่ายของคุณได้
- เก็บลิงก์ `dsh web` ไว้เป็นความลับ ใครก็ตามที่มีลิงก์นี้จะลงชื่อเข้าใช้ได้จนกว่า harness จะรีสตาร์ท

## ความเข้ากันได้

DSH Mobile ทดสอบกับ **DeepSeek Harness 0.2.2-rc.1** ส่วน harness เวอร์ชันเก่าย้อนไปถึง
0.1.6 ส่วนใหญ่ยังใช้งานได้ แต่ฟีเจอร์ใหม่ ๆ ต้องใช้ harness ที่ใหม่กว่า
[ตารางความเข้ากันได้](docs/COMPATIBILITY.md) บอกว่าแอปเวอร์ชันไหนใช้คู่กับ harness เวอร์ชันไหน

## บิลด์จากซอร์สโค้ด

```sh
./gradlew :app:assembleDebug      # debug APK
./gradlew :app:assembleRelease    # release APK, signed when the keystore environment is set
./gradlew :core:jvmTest :app:testDebugUnitTest
```

ถ้าจะตรวจแอปกับ harness ตัวจริง ให้บิลด์ harness จากซอร์สที่ checkout ไว้ แล้วรันชุดทดสอบ conformance:

```sh
DSH_HARNESS_SRC=/path/to/deepseek-harness ./gradlew :conformance:test
```

บิลด์สำหรับปล่อยรุ่นจะเอาเลขเวอร์ชันมาจาก git tag
ส่วน [CONTRIBUTING.md](CONTRIBUTING.md) อธิบายรอบการพัฒนา โครงสร้างโมดูล และขั้นตอนการปล่อยรุ่น

| พาธ | สิ่งที่อยู่ข้างใน |
|---|---|
| `app/` | แอป Android: หน้าจอต่าง ๆ, การเชื่อมต่อ, การแจ้งเตือน, คำแปล |
